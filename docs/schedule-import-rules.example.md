# 予定取り込みルール（例）

自由形式の連絡文をTimeTree登録用JSONへ整形するときは、個人用のルールを
`data/schedule-import-rules.md` に保存します。`data/` はGit管理対象外です。

個人用ルールには次の項目を記載します。

## 対象者

- 対象者名
- 学年・年齢
- 性別
- TimeTreeラベル名
- チームや活動名

ラベルIDは固定せず、登録時にラベル名からAPIで解決します。

## 対象選別

- 登録対象になる学年・カテゴリ
- 対象外になる条件
- 判断できない予定の扱い
- 仮予定と時間未定の扱い

## 日時・場所・通知

- 年が省略された場合の判断方法
- 集合時刻と開始時刻の区別
- 通知の既定値
- 場所名の抽出方法
- 重複予定の扱い

## 安全な登録手順

1. AIで原文を予定候補・要確認・対象外に分ける
2. 人が登録候補を確認する
3. `data/imports/YYYY-MM/` にJSONを保存する
4. dry-runでラベルとAPI送信内容を確認する
5. `--commit` で登録する
6. TimeTreeから読み戻して件数と内容を照合する

個人用ルールや月別JSONをGitへ追加しないでください。
